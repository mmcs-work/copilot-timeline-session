VS Code extension for GitHub Copilot

Keep every Copilot change understandable.

Copilot Timeline Session creates Git checkpoints while you work with Copilot, then gives you one clean place to review, compare, keep, or discard the finished session.

Download the VSIXSee how it works
A simple flow

Start. Work. Review. Keep.

The extension stays out of your way while Copilot works, then turns the session into a clear Git decision.

01

Start a session

A temporary Git branch is created in your current project folder.

02

Use Copilot normally

Completed Copilot tasks become small Git checkpoints.

03

Review the timeline

See changed files, commit details, diffs, and captured prompts.

04

Keep or discard

Squash everything into one commit, or return safely to the original branch.

Review with confidence

A timeline built for human review.

Inspect individual checkpoints first, then compare the original branch with the final session result.

Designed for real projects

Git safety without the ceremony.

Local files stay local

Existing untracked and ignored files, such as `.env`, stay on disk and are not added to session commits.

One clean final commit

Keep the session to squash its tracked changes into one commit on the branch where you started.

Prompt context

Optionally capture submitted prompts and view them directly from the review timeline.

Get started

Install the VSIX and start your first session.

Download the latest VSIX release. In VS Code, open the Command Palette and choose Extensions: Install from VSIX.... Then reload VS Code and select Start Copilot Session.
